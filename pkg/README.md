# Public Packages

This directory contains packages that are intended to be used by external applications.

## Purpose

- **Public APIs**: Packages that external services can import and use
- **Shared Libraries**: Common utilities that can be reused across projects
- **Client Libraries**: SDK-style packages for interacting with this service

*Note: Packages in this directory should have stable APIs and good documentation.*

## Current Status

This directory is currently empty but will be populated as public APIs are developed.
